## 📦 Deployment Instructions

### Option 1: GitHub Pages (Recommended)

1. **Create a new repository** on GitHub named `Backlink9` (or any name you prefer)

2. **Push this code** to the repository:
   ```bash
   cd "F:\Github Backlinks for Calculator Archive\Backlink9"
   git init
   git add .
   git commit -m "Initial commit: Free Tax Calculator 2025"
   git remote add origin https://github.com/[your-username]/Backlink9.git
   git branch -M main
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - Go to your repository on GitHub
   - Click **Settings** → **Pages**
   - Under **Source**, select **Deploy from a branch**
   - Select **main** branch and **/ (root)** folder
   - Click **Save**

4. **Your site will be live** at: `https://[your-username].github.io/Backlink9/`

### Option 2: Custom Domain (Optional)

1. Add a `CNAME` file with your custom domain
2. Configure DNS records at your domain registrar:
   - Add an `A` record pointing to GitHub Pages IPs
   - Or add a `CNAME` record pointing to `[your-username].github.io`
